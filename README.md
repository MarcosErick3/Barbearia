# ✂️ Barber Club | Barbearia

Landing page moderna e responsiva para uma barbearia, desenvolvida como **protótipo comercial de portfólio**.

## 🌐 Demonstração

**GitHub Pages:** https://marcoserick3.github.io/Barbearia/

**Repositório:** https://github.com/MarcosErick3/Barbearia

## ✨ Sobre o projeto

O Barber Club foi pensado como uma página comercial para apresentar uma barbearia de forma profissional, com foco em **conversão para agendamento**, identidade visual premium e boa experiência em dispositivos móveis.

A proposta pode ser adaptada para uma barbearia real, substituindo nome, fotos, preços, endereço, horários e número do WhatsApp.

## 🚀 Funcionalidades

- Hero section com chamada para agendamento
- Botões de conversão para WhatsApp
- Seção de serviços e preços
- Apresentação da barbearia
- Galeria de ambiente e atendimento
- Informações de horário, localização e contato
- Menu responsivo para celular
- Layout adaptado para desktop, tablet e mobile
- Animações e microinterações em CSS
- Navegação por âncoras
- Meta description para apresentação básica em mecanismos de busca
- Respeito à preferência `prefers-reduced-motion`

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## 📱 Responsividade

O layout foi construído com abordagem responsiva para oferecer uma experiência consistente em:

- 📱 Smartphones
- 📲 Tablets
- 💻 Notebooks
- 🖥️ Desktops

## 💼 Objetivo comercial

Este projeto faz parte do meu portfólio de **desenvolvimento de sites para pequenos negócios**.

A estrutura foi pensada para demonstrar como uma página simples pode apresentar serviços, fortalecer a identidade da marca e direcionar potenciais clientes para um canal de atendimento, como o WhatsApp.

## ⚠️ Observação

Este é um **projeto demonstrativo**. A Barber Club, preços, endereço, telefone e demais informações exibidas no site são fictícios e devem ser substituídos pelos dados do cliente antes de uma publicação comercial.

As imagens utilizadas são provenientes do Unsplash e podem ser substituídas por fotos reais da empresa.
